## Исправленные проблемы

### Данные, REST и MCP

- Переименование проекта только сменой регистра больше не конфликтует с самим собой.
- Пустые после trim названия задач/проектов отклоняются; цвета проверяются как #RRGGBB.
- Создание/перенос задач в архивный проект отклоняется вместо исчезновения с доски.
- REST больше не обрезает доску молча до 500 задач; лимит MCP остаётся явным.
- Текстовый поиск включает теги, регистр Unicode и воспринимает `%`/`_` буквально.
- Ручной порядок карточек сохраняется внутри колонки; вставка перенумеровывает
  позиции, блокировки PostgreSQL берутся в стабильном порядке для конкурентных переносов.
- MCP сохраняет явно заданный приоритет при AI-категоризации; `due_date=""`
  снимает срок, отсутствие поля оставляет его неизменным.
- SQLite в локальной разработке включает foreign keys и Unicode lower(), как ожидали тесты.

### AI, безопасность и надёжность

- AI-черновики нормализуют заголовок до 200 символов; относительные даты получают
  текущую дату в настроенной TIMEZONE.
- Ошибки AI/STT не возвращают и не логируют сырой текст исключений с адресами/ключами.
- Проверка Origin учитывает схему, хост и порт, корректно обрабатывает IPv6
  и отклоняет невалидные заголовки без 500.
- Лимит входа резервирует попытку под блокировкой до проверки пароля:
  параллельные запросы больше не обходят лимит.
- Некорректный MCP-токен с не-ASCII символами отклоняется без TypeError.
- Размер аудиозапроса ограничен до multipart-разбора и записи временного файла;
  точный лимит аудио дополнительно проверяется в обработчике.
- `next` после входа отклоняет пути с обратными слешами/управляющими символами.
- Диктовка не вставляет запоздалый результат после закрытия редактора.
- При сетевом сбое AI длинная заметка остаётся сохраняемой: 200 символов в заголовке,
  полный исходный текст в описании.

### Интерфейс

- Ссылка `?task=` загружает задачу отдельным GET, независимо от фильтра и окна Done.
- Добавлены управление проектами (создание, описание/цвет/имя, архив,
  восстановление, удаление с подтверждением) и фильтр по тегу в URL.
- Есть переключатель старых завершённых задач; на мобильном он не перекрывается
  закреплённым полем быстрого ввода.
- Мобильные drop-зоны находятся внутри DndContext; карточки стали целями сортировки.
- Ошибки переноса видны пользователю; некорректный priority в URL не ломает загрузку.
- Обработка конфликта при создании проекта применяется только к HTTP 409:
  сетевые ошибки больше не выдаются за архивный проект.

### Эксплуатация и зависимости

- Бэкап больше не скрывает ошибку pg_dump за успешным gzip. Сначала создаётся
  временный дамп, затем сжатый файл публикуется переименованием. При ошибке
  временные файлы удаляются; ротация выполняется после успеха.
- CI получает отдельный PostgreSQL для интеграционных проверок и тестовый
  POSTGRES_PASSWORD для разрешения compose-конфигурации на стадии build.
- Обновлены Vite, Vitest, React Router, plugin-react и уязвимые транзитивные пакеты;
  cryptography обновлён с 49.0.0 до 50.0.1. Vitest-конфигурация адаптирована к v4.
- npm audit: до исправлений 9 уязвимостей, включая 1 critical; после — 0.
  Python pip-audit: после обновления — 0 известных уязвимостей.
