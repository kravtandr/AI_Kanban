# ADR-0010 Полное покрытие возможностей портала через MCP

- Статус accepted
- Дата 2026-11-17

## Контекст

Владелец запросил полное покрытие функций портала через MCP и переработку вкладки
интеграции. Бюджет, управление проектами, часть операций трат и AI-действия ранее
были доступны только через REST. ADR-0009 ограничивал MCP трат четырьмя инструментами.

## Решение

Расширяем MCP аддитивно, сохраняя имена, прежние параметры, значения по умолчанию
и формат существующих результатов. Добавляем параметры в конец сигнатур.
ADR-0009 в части отсутствия удаления трат заменяется этим решением.

Все бизнес-возможности портала доступны через инструменты проектов, задач, трат,
бюджета, аналитики и AI. Операции используют существующие сервисы и схемы.
Пользователь бюджета определяется как единственный владелец сервиса, аналогично
API-токену. Суммы бюджета передаются целыми копейками, как в REST. Повтор сохранения
месяца заменяет тот же месяц атомарным upsert. Цели соответствуют формулам UI.

Для диктовки принимаем аудио в base64 с ограничением размера из конфигурации STT.
Сервер декодирует его в памяти. Сессии браузера обслуживает существующая
авторизация, MCP-клиенты продолжают использовать Bearer-токен.

Вкладка MCP получает поиск, фильтры по разделам, русские описания, панель параметров,
примеры JSON и копируемые настройки. Реестр MCP остаётся источником схем.
Настройки отображения интерфейса сохраняют назначение клиентских предпочтений.

## Альтернативы

Отдельные реализации бизнес-операций в MCP увеличивают расхождение между интерфейсами.
Повторное использование сервисов сохраняет общие проверки и транзакции.

## План реализации и проверки

1. Добавить регрессионные тесты MCP для каждого нового сценария и расширенных параметров.
2. Вынести бюджетный upsert и чтение в общий сервис и расширить MCP.
3. Проверить равенство бизнес-маршрутов REST и MCP явной матрицей в тестах.
4. Переработать вкладку с сохранением общей навигации и существующей типографики
   IBM Plex Sans / Mono. Палитра night #0e1116, surface #151a21, edge #2a3441,
   ink #e9e5da, MCP #56b6c2, AI #9d8cff.
5. Проверить фильтрацию, параметры, копирование, состояния ошибок и мобильную раскладку.
6. Выполнить make setup, make test-fast и make verify.

## Последствия

Новые инструменты дают MCP-клиенту те же возможности изменять данные, что и портал.
Удаление проекта с задачами требует явного force. AI-операции вызываются явно.
Контракт REST и схема базы сохраняются.
