# ADR-0004: Модель сетевого доступа

- **Статус**: accepted (утверждено владельцем 2026-07-22)
- **Дата**: 2026-07-22

## Контекст

Трекер развёрнут на домашнем сервере; нужен доступ с десктопа, телефона и для MCP-агентов.

## Решение

**Только локальная сеть.** Порты наружу не пробрасываются, публичный домен не заводится.
Caddy отдаёт приложение по HTTP на :80 внутри доверенной LAN (deploy/Caddyfile).
Cookie без флага Secure допустимы в этой модели (см. ADR-0003); при включении HTTPS
через `tls internal` установить `APP_ENV=prod`.

## Альтернативы

- Tailscale/VPN — хорошая будущая опция, добавляется без изменений кода (тот же Caddy).
- Публичный домен + проброс порта — отклонено владельцем: неоправданный риск для
  персонального сервиса.

## Последствия

- Внешний (вне дома) доступ отсутствует до отдельного решения о VPN.
- Открытый вопрос: HTTP в доверенной LAN vs `tls internal` с доверием CA на устройствах —
  решается владельцем при деплое, инструкция в Caddyfile.
