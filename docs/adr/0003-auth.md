# ADR-0003: Схема авторизации

- **Статус**: accepted
- **Дата**: 2026-07-22

## Контекст

Один пользователь-владелец; отдельная страница входа; программный доступ для агентов.

## Решение

- Серверные сессии: непрозрачный токен в HttpOnly/SameSite=Lax cookie (`tt_session`),
  в БД — только SHA-256 хэш; TTL 30 дней. `Secure` включается при `APP_ENV=prod` c HTTPS.
- Пароль — argon2id (argon2-cffi). Учётка создаётся из env при первом старте или CLI.
- Rate limiting входа: 5 попыток / 5 минут / IP (in-memory).
- Программный доступ: статические Bearer-токены в таблице `api_tokens`
  (kind = `api` для REST, `mcp` для MCP), хранятся хэшами, отзыв по одному.
- CSRF: JSON-only API + SameSite=Lax признаны достаточными для LAN-развёртывания MVP.

## Альтернативы

JWT — отклонено (нет нужды в stateless, отзыв сложнее); OAuth для MCP — вне рамок MVP.

## Последствия

Logout инвалидирует сессию удалением записи. Многопользовательность потребует
только расширения таблицы users (архитектура не блокирует).
